# E-Commerce Backend Simulation

A JavaScript-based E-Commerce simulation project that manages products, shopping carts, and order processing.

## Features

- Display all products
- Search products by name
- Filter products by category
- Sort products by price
- Add and remove products from cart
- Increase and decrease product quantities
- Prevent adding products beyond available stock
- Calculate cart subtotal and total items
- Apply coupon codes (SAVE10 and SAVE20)
- Calculate discount, tax, and final amount
- Place and cancel orders
- Generate unique order IDs
- Maintain order history
- Simulate asynchronous checkout using Promises and async/await
- Handle checkout errors using try...catch
- Save cart data using LocalStorage

## Technologies Used

- HTML
- CSS
- JavaScript
